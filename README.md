## 项目简介
**MuMu **是一款融合**情感陪伴**、**离线语音交互**、**双蓝牙控制**与**音乐播放**功能的智能桌面机器人。整机以 STM32F103C8T6 为核心，通过 1.3 英寸 OLED 呈现开心、惊讶、左右张望、无聊和生气等动态眼睛表情，并利用两路 SG90 舵机驱动左右手，完成立正、打招呼、上才艺和稍息等拟人化动作。用户既可以通过 SU-03T 离线语音模块自然下达指令，也可以借助 JDY-31 串口蓝牙实现手机远程控制；M38 蓝牙功放模块搭配左右声道扬声器，还能让 MuMu 直接连接手机播放音乐，使机器人同时具备互动陪伴和桌面蓝牙音箱两种角色。项目采用模块化双 PCB 与铜柱结构，兼具低门槛、易复现和强扩展性，可应用于桌面情感陪伴、青少年编程教育、创客实践和科技展示等场景。未来，MuMu 将进一步加入锂电池供电、3D 打印外壳、环境感知等功能，逐步成长为可持续扩展的智能桌面机器人平台。

## 项目功能
- MuMu 定位为“**会看、会听、会动、会回应**”的低成本互动伙伴。平时，MuMu 会在 OLED 上随机播放眼睛表情并自然眨眼，使设备具有拟人化的情绪表现。用户通过 SU-03T 发出语音指令后，系统会根据命令实时切换表情并驱动两个 SG90 舵机完成对应动作：立正时双手向下并显示开心，打招呼时右手摆动并显示惊讶，上才艺时双手快速摇摆并依次显示左右张望和无聊，稍息时双手抬起并显示生气。动作结束后，机器人自动回到初始姿态和随机表情，形成完整的“**语音输入—表情反馈—动作输出**”交互闭环。
- **在无线与音频方面**，MuMu 通过 JDY-31 接收手机或上位机的蓝牙控制命令，便于后续扩展远程动作控制、参数调试和自定义交互；**M38 蓝牙功放模块则可直接连接手机播放音乐**，使 MuMu 同时成为一台具有左右声道输出的**桌面蓝牙音箱**。语音识别通道、控制通道和音乐播放通道相互独立，机器人既能执行动作指令，也能播放音乐和语音提示，兼顾陪伴、娱乐和交互功能。
- 在应用场景上，MuMu 可用于**桌面情感陪伴**，通过表情、眨眼和挥手为用户提供轻量、持续的反馈；也可用于中小学、高校和创客空间的编程与电子教学，帮助学生理解 STM32、PWM、串口通信、定时器、OLED 显示和人机交互，并在此基础上继续增加传感器、语音指令和动作。此外，MuMu 适合科技节、创客展、社团招新和直播演示，通过语音控制表情与动作，配合手机蓝牙音乐，直观展示软硬件协同效果。后续计划增加 3.7V 锂电池、3D 打印外壳、人体感应与温湿度传感器、手机 App 和更多扩展指令，使 MuMu 逐步发展为可复现、可开源、可持续扩展的桌面机器人平台。

## 项目参数
- **主控平台**：STM32F103C8T6，ARM Cortex-M3 内核，采用 Keil MDK 与 STM32 标准外设库开发。
- **显示模块**：1.3 英寸 128×64 OLED，I²C 接口连接 PB8、PB9，用于显示 5 种动态眼睛表情与眨眼动画。
- **语音模块**：SU-03T 离线语音识别模块，USART1 通信，波特率 9600，自带咪头麦克风和 8Ω/0.25W 扬声器。
- **运动模块**：两路 SG90 舵机作为左右手，分别连接 PA2、PA3，由 TIM2 输出 50Hz PWM 控制，PCB 预留 4 路舵机接口。
- **无线控制**：JDY-31 串口蓝牙模块连接 USART3 的 PB10、PB11，波特率 115200，用于手机或上位机指令控制。
- **音频播放**：M38 蓝牙功放模块采用 5V 供电，外接左右声道两个 8Ω/0.25W 扬声器，可直接连接手机播放音乐。
- **电源方案**：当前采用外部 5V 输入，后续计划使用 3.7V 锂电池，经 5V 充放电一体模块输出稳定 5V，再由 STM32 核心板转换为 3.3V。
- **结构方案**：当前采用两块 PCB 与铜柱组成主体结构，后续将设计并打印 3D 外壳。

## 原理解析（硬件说明）
- **MuMu **采用**模块化设计**，整体由主控与显示、语音识别、舵机动作、双蓝牙通信、音频播放和电源管理六部分组成。系统以 STM32F103C8T6 为中心，通过 UART 接收语音模块和串口蓝牙模块的指令，通过定时器 PWM 控制两个 SG90 舵机，通过 I²C 驱动 1.3 英寸 OLED 显示表情，并允许 M38 蓝牙功放独立完成手机音乐播放。接收到有效指令后，主程序会先切换表情，再启动对应舵机动作；动作结束或收到新指令时，系统自动回到初始状态并恢复随机表情播放。
- **主控与显示部分**使用 STM32F103C8T6 负责命令解析、表情状态维护、PWM 波形生成和多模块调度。OLED 通过 PB8、PB9 与主控通信，程序采用显存缓冲和局部区域刷新提高动画流畅度。由于 OLED 采用倒装结构，初始化时使用 0xA0 与 0xC0 指令让整块屏幕旋转 180°，无需逐帧修改表情数据。
- **语音交互**由 SU-03T 离线语音模块完成，模块自带咪头和扬声器，用户无需联网即可通过“你好慕木”等唤醒词进入识别状态。识别到“立正、打个招呼吧、上才艺、稍息”等命令后，模块通过 USART1 向 STM32 发送 0x31、0x32、0x33、0x34，主程序据此触发表情与舵机动作。
- **动作系统**使用两个 SG90 舵机模拟左右手，PA2 控制左手，PA3 控制右手，TIM2 的通道 3、通道 4 输出 50Hz PWM 信号。为了同时兼顾 OLED 动画与舵机摆动，程序使用 TIM3 定时中断在后台更新舵机角度，使表情播放和动作控制可以并行执行。左右舵机采用镜像安装和独立角度参数，便于校正旋转方向与初始位置。
- **无线通信与音频播放**采用双蓝牙架构。JDY-31 串口蓝牙负责控制数据传输，连接 USART3，接收手机或上位机的动作指令；M38 蓝牙功放负责音频播放，直接连接手机蓝牙并由 5V 供电，驱动左右声道两个 8Ω/0.25W 扬声器。控制与音频通道相互独立，机器人可以一边执行动作，一边播放手机音乐。

## 软件代码
工程采用 STM32 **标准外设库**开发，代码按主程序、OLED 表情、舵机动作、语音与蓝牙通信等模块划分。完整工程源码见项目附件，核心命令调度逻辑如下：
```
#define MUMU_CMD_UPRIGHT  0x31
#define MUMU_CMD_GREET    0x32
#define MUMU_CMD_TALENT   0x33
#define MUMU_CMD_REST     0x34

while (1)
{
    Command = BlueTooth_GetCommand();

    if (Command == MUMU_CMD_UPRIGHT)
    {
        MuMu_MoveArmsDown();
        MuMuFace_ShowHappyOnce();
        Servo_ReturnToInit();
    }
    else if (Command == MUMU_CMD_GREET)
    {
        Servo_StartRightWave(MUMU_RIGHT_ARM_INIT_ANGLE,
                             MUMU_GREET_LOW_ANGLE,
                             MUMU_GREET_HALF_PERIOD_MS,
                             MUMU_GREET_TOTAL_MS);
        MuMuFace_ShowSurprisedOnce();
        Servo_ReturnToInit();
    }
    else if (Command == MUMU_CMD_TALENT)
    {
        Servo_StartBothSwing(180.0f, 0.0f, 250, 4000);
        MuMuFace_ShowLookAroundOnce();
        MuMuFace_ShowBoredOnce();
        Servo_ReturnToInit();
    }
    else if (Command == MUMU_CMD_REST)
    {
        Servo_StartBothHold(120.0f, 2000);
        MuMuFace_ShowAngryOnce();
        Servo_ReturnToInit();
    }

    MuMuFace_PlayRandomEmotion();
}
```

## 注意事项
- **OLED 为倒装结构**，驱动初始化必须保持 0xA0 与 0xC0 指令，否则表情和文字都会颠倒。
- **语音模块** USART1 使用**9600**波特率，JDY-31 蓝牙模块 USART3 使用**115200**波特率。
- M38 功放和 SG90 舵机均使用 5V 供电，舵机启动电流较大，建议使用**独立且电流充足**的 5V 电源。
- 舵机**初始角度和立正角度**可在 main.c 中通过四个独立宏调整，防止不同安装方向造成动作反向或卡死。
- 执行长时间动作时，如果收到新的 0x31~0x34 指令，程序会**中断当前动作并执行新命令**。
- **M38** **左右声道扬声器接线**必须区分 L± 与 R±，避免左右声道接反或短路。至于保险丝，主包是为了防止扬声器正负极短接烧坏M38功放，**因为我之前已经烧坏了两块M38模块了，都是因为意外的短接导致的不可逆转的损失，大家一定要做好防护措施。**
